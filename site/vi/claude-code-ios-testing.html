Test app iOS bằng Claude Code hoặc Codex

Cập nhật lần cuối: 16/11/2026

AI-OS là app Mac miễn phí kiêm MCP server chạy ngay trên máy. AI agent của bạn gửi các bước của một bài test; AI-OS chạy chúng trên iOS simulator hoặc iPhone thật, nhìn màn hình trước mỗi bước, rồi báo lại chuyện gì đã xảy ra. Hướng dẫn này đi từ lúc tải về tới lúc test app của chính bạn.

Bạn cần gì

  • Mac chip Apple silicon, macOS 26 (Tahoe) trở lên.
  • Xcode 26 trở lên. Nếu chưa có, setup sẽ mở App Store.
  • Claude Code, Claude Desktop, Codex hoặc một MCP client khác.
  • Một bản build simulator của app. Với iPhone thật, xem Test trên iPhone thật.

1. Cài AI-OS

  1. Tải AI-OS về và mở file zip.
  2. Mở AI-OS.app. Lần đầu, macOS sẽ chặn: mở System Settings, Privacy & Security, rồi bấm Open Anyway.
  3. Bấm Set up. Nó chỉ cài những gì Mac còn thiếu (iOS cho simulator, driver simulator và simslim) và hiện rõ từng bước.

2. Kết nối AI agent

Setup tự kết nối AI-OS với Claude Code, Claude Desktop và Codex nếu máy bạn có. Muốn kết nối sau, mở app AI-OS, vào Settings, AI connection:

  • Claude Code: bấm Register in Claude Code, rồi mở một phiên Claude Code mới.
  • Claude Desktop: bấm Add to Claude Desktop, rồi khởi động lại Claude Desktop.
  • Codex: bấm Register in Codex, rồi mở một phiên Codex mới.

Làm từ Terminal cũng được:

~/ai-os/bin/aios connect --claude-code
~/ai-os/bin/aios connect --claude-desktop
~/ai-os/bin/aios connect --codex

Với MCP client khác, lệnh này cho biết cái gì đã kết nối và in ra cấu hình server để chép vào MCP config của client đó:

~/ai-os/bin/aios connect

Lần đầu một phiên AI dùng mỗi tool của AI-OS, Claude Code sẽ hỏi bạn có cho phép không, và agent chờ bạn bấm. Muốn cho phép mọi tool của AI-OS một lần, thêm dòng này vào ~/.claude/settings.json:

{"permissions": {"allow": ["mcp__ai-os"]}}

3. Chạy test đầu tiên

Dán câu này cho agent:

Dùng AI-OS: bật một iPhone simulator, mở app Settings và cho tôi biết màn hình đầu tiên hiện gì.

Agent bật simulator, mở Settings và đọc màn hình dưới dạng chữ.

4. Test app của bạn

Trên simulator, AI-OS cài file .app build cho iOS Simulator, hoặc file .zip chứa nó.

  • Xcode: build với destination là iOS Simulator.
  • Flutter: chạy flutter build ios --simulator
  • File .ipa, link TestFlight hay bản build cho iPhone thật thì không chạy được trên simulator.

Chọn thư mục build trong app AI-OS (Settings, Logins) rồi gọi bản build theo tên, hoặc đưa agent đường dẫn tới nó. Sau đó mô tả bài test bằng lời thường, ví dụ:

Dùng AI-OS: cài mới MyApp.app trên một iPhone simulator, đăng nhập bằng tài khoản test với mật khẩu đã lưu tên APP_PASSWORD, rồi kiểm tra màn hình Home có chữ Welcome.

Một bài test trông thế nào

Agent gửi mọi bước của bài test trong một lần gọi. AI-OS đọc màn hình trước mỗi bước, chờ tới khi màn hình đứng yên, rồi kiểm tra kết quả:

[{"tap": "Log in"},
 {"fill": {"field": "Email Address", "text": "qa@example.com"}},
 {"type_secret": {"field": "Password", "key": "APP_PASSWORD"}},
 {"wait_for": "Home", "timeout": 8},
 {"assert": "Welcome"}]
  • Khi một bước không đi tiếp được, ví dụ vì một hộp thoại không ai lường trước, AI-OS hỏi lại agent thay vì treo, kèm màn hình và những phần tử gần giống nhất.
  • Mật khẩu được gõ theo tên. Giá trị thật không bao giờ tới tay AI.
  • Mỗi lần AI chạy đều vào lịch sử chạy trong app AI-OS, kèm các bước và ảnh chụp nếu có. Mật khẩu đã được xoá.

Đo ngày 3/11/2026, cùng một test Contacts do Claude Code với Claude Sonnet chạy: AI-OS pass 5/5 với 6 lượt agent (trung vị); các tool khác cần 19 đến 21 lượt. Xem AI-OS so với các tool khác.

Tải cho Mac

Dùng miễn phí. Cho Mac dùng Apple silicon, macOS 26 (Tahoe) trở lên và Xcode 26 trở lên.
