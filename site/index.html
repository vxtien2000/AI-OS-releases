A test is a list of steps

stepsAI-OS
  1. {"tap": "Log in"}

    Taps only an enabled target.

  2. {"fill": {"field": "Email Address", "text": "qa@example.com"}}

    Finds the box by label, types, checks.

  3. {"type_secret": {"field": "Password", "key": "APP_PASSWORD"}}

    Types a saved password; replies show [secret].

  4. {"wait_for": "Home", "timeout": 8}

    Waits by looking, never by sleeping.

  5. {"assert": "Welcome"}

    Exact label or whole words, with case.

Questions, not hangs

A step that cannot go on asks your agent.

The first time

“Save Password?” covers the screen. The run returns a question; the agent answers and goes on.

Every time after

A rule taps through it.

{"when": "Save Password?", "tap": "Not Now"}

aios_runSeveral devices at once, in the background.
aios_captureScreenshot, video start and stop.
